# nirwal-plugins

A Claude Code plugin marketplace.

## Plugins

| Plugin | Description |
|---|---|
| [llm-wiki](llm-wiki/) | Karpathy-style LLM wikis per research topic, with ingest, query and lint commands. Works with ZenNotes, Obsidian or a plain folder. |

## Install

```
/plugin marketplace add <path or GitHub repo of this marketplace>
/plugin install llm-wiki@nirwal-plugins
```
